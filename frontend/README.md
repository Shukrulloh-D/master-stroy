# 🏗️ Master Stroy — Landing Page

Одностраничный сайт (лендинг) для компании-производителя тротуарной плитки «Мастер Строй». 
Проект выполнен в рамках учебного курса, но спроектирован как полноценный коммерческий продукт с использованием современных подходов к архитектуре и управлению состоянием.

## 🚀 Технологический стек

**Frontend:**
- ⚛️ **React** (с использованием Vite)
- 🏗️ **Feature-Sliced Design (FSD)** — архитектурная методология
- 🔄 **TanStack React Query** — управление серверным состоянием (кэширование, загрузка)
- 📡 **Axios** — HTTP-клиент для работы с API
- 🎨 **CSS Modules** — изолированные стили
- 🌐 **React Context** — управление клиентским состоянием (Корзина)

**Backend (Mock API):**
- 🟢 **Node.js + Express**
- 📦 **JSON-база данных** (эмуляция работы с БД)

## ✨ Основные фичи

- **Адаптивная верстка** по макету Figma.
- **Динамический каталог:** данные (товары, категории, преимущества) приходят с бэкенда.
- **Умная корзина:** выезжающая панель (Drawer), подсчет итоговой суммы, выбор цвета товара, удаление позиций.
- **Модальные окна:** быстрый просмотр товара, форма обратного звонка с валидацией и состоянием успеха.
- **Скелетон-загрузка:** мерцающие заглушки во время запроса данных (как в YouTube/VK).
- **UX-улучшения:** плавный скролл по якорям, кнопка «Наверх», hover-анимации, плавное появление элементов.
